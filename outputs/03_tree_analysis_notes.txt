
BASELINE TREE ANALYSIS
========================
1. Most important feature: Sex (0.317),
   followed by Age (0.270).
   -> Consistent with real-world knowledge: gender (Sex) and fare (Fare)/
      passenger class (Pclass) are the strongest factors influencing survival
      on the Titanic ("Women and children first").

2. Tree depth = 23, number of leaves = 153 on only 712 training samples.
   -> The tree is TOO DEEP / TOO COMPLEX relative to the dataset size.
   -> Many leaves contain only 1-2 samples (the tree has "memorized" individual
      training cases).

3. Comparing Train Accuracy (98.17%) vs Test (82.12%):
   -> A gap of ~16% -> a clear sign of OVERFITTING.
   -> Cause: no max_depth limit, default min_samples_leaf = 1, so the tree
      keeps splitting until every leaf is pure.

=> CONCLUSION: regularization techniques (limiting depth, increasing
   min_samples_leaf, pruning, etc.) should be applied in the improvement
   stage to reduce overfitting and improve generalization on new data.
