
RESULTS DISCUSSION
==================
1. The baseline (no constraints) achieved Test Accuracy = 0.8212 but
   Train Accuracy = 0.9817
   -> a very large train-test gap -> SEVERE OVERFITTING.

2. Improvement 1 (max_depth=16) improved Test Accuracy to
   0.8380, while also significantly reducing the train-test gap
   -> shows that limiting depth helps the model generalize better.

3. Improvement 2 (criterion + min_samples_leaf, selected via GridSearchCV) achieved
   Test Accuracy = 0.7765. Although the CV score on train was high,
   the test result did not outperform the baseline -> clearly illustrates that
   choosing parameters optimal by CV does not always guarantee the best result
   on the actual test set (due to random variation / grid complexity).

4. Improvement 3 (Cost-Complexity Pruning, alpha selected via 5-fold CV) sharply
   reduced tree complexity (from depth=23, 153 leaves -> depth=10, 24 leaves) while
   Test Accuracy (0.7821) remained at an acceptable level and the tree
   is much simpler and easier to interpret.

=> CONCLUSION: 'Improvement 1: max_depth tuning' gives the highest Test Accuracy among all
   the methods tested. However, if simplicity/interpretability of the tree is
   prioritized, Cost-Complexity Pruning is a good balance between accuracy and
   model complexity.
